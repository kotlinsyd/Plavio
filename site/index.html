Why Plavio

🎬 Your addons

Install any Stremio-protocol addon via its manifest URL. Star favorites, reorder freely.

▶️ Built-in player

Gesture controls, subtitles, audio tracks, resume playback, skip intro.

📺 Live TV

A dedicated tab for your live streams.

🔄 In-app updates

The app tells you when a new version is out and updates itself.

🌙 Made for the dark

A glass-glow dark interface designed for movie nights.

🔓 Open source

The code is public. No trackers, no ads, no nonsense.

How to install

  1. Tap one of the Download buttons above — the file saves to your phone.
  2. Open the downloaded file from your notifications or Downloads.
  3. Allow unknown sources when Android asks — the APK comes straight from the developer's official release page, so it's safe to install.
  4. Tap Install, then open Plavio and enjoy.

Updating later is easy: the app notifies you and installs the update itself.

Recommended addons

Copy a link, then in Plavio go to Addons → + and paste it. That's it.
