How to install

  1. Tap one of the Download buttons above — the file saves to your phone.
  2. Open the downloaded file from your notifications or Downloads.
  3. Allow unknown sources when Android asks — the APK comes straight from the developer's official release page, so it's safe to install.
  4. Tap Install, then open Plavio and enjoy.

Updating later is easy: the app notifies you and installs the update itself.

Recommended addons

Copy a link, then in Plavio go to Addons → + and paste it. That's it.

Frequently asked questions

Is Plavio free?

Yes. Plavio is free forever — no ads, no trackers, no subscriptions. Download the APK right here on the official site.

Does Plavio work on Android TV?

The Android TV version is currently under development — something big is coming soon.

How do I install addons?

Copy the addon's manifest URL, open Plavio, go to Addons and tap +, then paste the link. The addon installs instantly and its catalogs show up in the app.

Is Plavio open source?

Yes. The full source code is public on GitHub and GitLab under the MIT license — inspect it, fork it, contribute to it.
