# Contributing to Plavio

Thanks for helping. Plavio is a small project and every fix counts.

## Ways to help
- Report bugs: open an issue and tell me what you did, what happened, and your phone/TV model and Android version.
- Test new builds: release pages have the APKs. Trying a build on your device and reporting back helps a lot.
- Code: fork the repo, make your change, and open a pull request.

## Building the app
- You need JDK 17 and the Android SDK (API 35).
- Clone your fork, open the project in Android Studio, and run the app, or build from the terminal:
  ./gradlew assembleRelease

## Pull requests
- Keep changes small and focused. One fix per pull request.
- Write a short note on what you changed and why.
- If you changed how something looks, add a screenshot.

## House rules
- Be kind. Short and clear beats long and fancy.
